# React Todo App

A simple Todo List application built using React.  
This project was created to practice React fundamentals such as state management, component structure, and hooks.

## Live Demo
https://your-vercel-link.vercel.app

## Features
- Add new tasks
- Mark tasks as completed
- Remove tasks
- Clear all tasks
- Tasks stored using localStorage
- Responsive UI using Bootstrap

## Tech Stack
- React
- JavaScript
- Vite
- Bootstrap

## Installation

Clone the repository:

git clone https://github.com/Hitesh1236/react-projects.git

Navigate to the project folder:

cd react-projects/to-do-app

Install dependencies:

npm install

Run the development server:

npm run dev
